# AI-DocAgent
> 通用化AI文档解析&自动化结构化处理Agent框架 | 全链路文档智能处理工作流解决方案

## 项目简介
AI-DocAgent 是基于Python+Shell构建的通用非结构化文档自动化处理引擎，依托大模型能力实现多格式文档解析、内容抽取、数据标准化、自动化批量调度全流程。
框架采用模块化插件化设计，可灵活适配合同、试卷、资讯、行业文档等各类非结构化数据源结构化落地场景，内置断点续传、任务监控、数据质检、接口容错等工程化能力。

## 技术栈
- 开发语言：Python3、Shell
- 存储：MySQL(任务元数据)、MongoDB(原始文档存储)、Redis(缓存、限流、任务临时标记)
- AI能力：兼容各类通用大模型开放API（通义千问/智谱AI/OpenAI等）
- 数据处理：BS4、正则表达式、JSON/JSONL解析、MD5数据去重
- 运维调度：Linux环境脚本调度、批量文件处理

## 六大核心模块
1. 多格式文档解析模块
2. LLM信息抽取模块
3. 统一结构化转换模块
4. 数据质量校验模块
5. 批量任务调度模块
6. 自定义插件扩展模块

## 核心特性
1. 任务断点自愈：自定义状态文件记录任务进度，异常中断后自动续跑，规避重复处理损耗
2. 插件化规则：支持自定义抽取Prompt、清洗规则，按需拓展业务逻辑
3. 全链路自动化：从原始文档入库→解析→抽取→结构化→质检全流程无人值守调度
4. 通用容错机制：API请求重试、熔断降级、UA动态池、异常数据隔离
5. 标准化输出：统一JSON/JSONL结构化数据格式，方便下游系统对接

## 适用落地场景
通用办公文档结构化、行业资料信息提取、非标文本规整、知识库素材构建（后续拓展：QA问答素材抽取场景）

## 项目规划
1. 第一阶段（当前）：架构文档、模块设计、问题方案落地（本仓库现有内容）
2. 第二阶段：分模块逐步开发源码，实现最小可用版本
3. 第三阶段：拓展更多解析插件、调度优化、部署脚本
