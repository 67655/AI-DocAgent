# AI-DocAgent 快速开始指南

## 环境要求
- Python 3.8+
- pip 包管理器

## 1. 安装

```bash
# 克隆项目
git clone https://github.com/67655/AI-DocAgent.git
cd AI-DocAgent

# 运行环境初始化脚本
source shell/setup_env.sh
# 或在Windows下:
# shell\setup_env.sh (Git Bash)
```

## 2. 配置

编辑 `.env` 文件，填入API密钥：

```ini
# 至少配置一个LLM厂商
DASHSCOPE_API_KEY=sk-your-dashscope-key    # 通义千问
# ZHIPU_API_KEY=your-zhipu-key             # 智谱AI
# OPENAI_API_KEY=sk-your-openai-key        # OpenAI
```

## 3. 基本用法

### 3.1 文档解析
```bash
# 解析PDF/Word/TXT/HTML文档
docagent parse document.pdf -o result.json

# 纯文本输出
docagent parse document.txt -f text

# 查看支持的文件格式
python -c "from src.parser import parser_factory; print(parser_factory.get_supported_extensions())"
```

### 3.2 信息抽取
```bash
# 从文件抽取
docagent extract --file document.txt -o extracted.json

# 从文本直接抽取
docagent extract --text "今天天气晴朗，适合外出" --provider qwen

# 使用自定义Prompt插件
docagent extract --file contract.pdf --prompt generic_entity_extraction
```

### 3.3 数据校验
```bash
docagent validate --file extracted.json -o errors.json
```

### 3.4 批量处理
```bash
# 批量处理目录下所有文档
docagent batch --dir ./docs/ --shard-size 10 -o output.jsonl

# 从文件列表批量处理
docagent batch --file file_list.txt --provider openai
```

### 3.5 任务状态查询
```bash
docagent status
```

### 3.6 插件管理
```bash
# 列出所有插件
docagent plugins list

# 启用/禁用插件
docagent plugins enable whitespace_normalizer
docagent plugins disable html_tag_stripper

# 保存插件配置
docagent plugins save
```

## 4. Shell脚本方式

```bash
# 批量任务（支持断点续传）
bash shell/run_batch.sh --dir ./docs/ -o result.jsonl --shard-size 10

# 断点续传（中断后继续）
bash shell/run_batch.sh --dir ./docs/ --continue

# 单文件全流程处理
bash shell/run_single.sh document.pdf output/result.json
```

## 5. Python API调用

```python
import sys; sys.path.insert(0, 'src')

# 文档解析
from src.parser import parser_factory
result = parser_factory.parse("document.pdf")
print(result.paragraphs[:5])

# LLM抽取
from src.extractor import InfoExtractor
extractor = InfoExtractor(provider="qwen")
result = extractor.extract("需要抽取的文本...")

# 结构化转换
from src.converter import converter
standardized = converter.convert_llm_response(result)

# 质量校验
from src.validator import quality_validator
report = quality_validator.validate(standardized)
print(report["pass"])

# 任务调度（断点续传）
from src.scheduler import scheduler
items = ["file1.pdf", "file2.pdf", "file3.pdf"]

def process(path):
    from src.parser import parser_factory
    return parser_factory.parse(path).to_dict()

result = scheduler.create_and_run(items, process_func=process, shard_size=2)
```

## 8. 常见问题

**Q: 提示 "API Key 未配置"？**
A: 检查 `.env` 文件中是否正确配置了API密钥，并确保已 `source .env` 或重启终端。

**Q: 如何添加新的LLM厂商？**
A: 继承 `BaseLLMClient` 实现 `chat()` 方法，然后通过 `llm_factory.register()` 注册。

**Q: 断点续传如何工作？**
A: 任务执行时自动保存进度到 `status/task_runtime_status.json`，重新运行时会自动跳过已完成分片。

**Q: 如何自定义输出格式？**
A: 使用 `OutputSchema` 定义自定义Schema，或通过插件系统注册 `CleanRulePlugin`。
